Logo digitising – creating your embroidery file

We convert your logo into a professional embroidery file (digitising, also called punching) and use it to embroider your textiles. Before the run you receive a sample for approval.

From logo file to embroidery file

A logo cannot be embroidered directly. First the graphic is turned into an embroidery file that tells the machine, stitch by stitch, where and in which direction to embroider. We do this digitising for you, check your logo in the process and agree size, position and thread colours with you.

  • Digitising (punching) of your logo by us
  • Up to 15 thread colours, Madeira premium thread
  • Embroidery sample for approval before the run
  • Saved embroidery file: on reorders with the same logo the setup does not apply

Which files do we need?

Ideally your logo as a vector file (AI, EPS, PDF or SVG). We also work with good PNG or JPG files. Chest logos are usually 7–10 cm wide, slightly smaller on caps. We recommend the right size for each garment and level of detail.

Frequently asked questions

What does digitising a logo mean?

The logo is converted into an embroidery file (digitising or punching). Only this file tells the embroidery machine how to embroider the logo.

Can I have my logo digitised at BRODIRA?

Yes. We create the embroidery file from your logo and embroider your textiles with it. Before the run you receive a sample for approval.

Which file format do I need for my logo?

Ideally a vector file (AI, EPS, PDF, SVG). Good PNG or JPG files work too.

What does digitising a logo cost?

The price depends on stitch count, garment and quantity. A setup fee may apply for the one-off digitising and is shown separately in the quote. It does not apply on follow-up orders with the same file.

How many colours can the embroidery have?

Up to 15 thread colours, with Madeira premium thread.
